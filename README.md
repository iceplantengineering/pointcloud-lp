# 点群計測 × リバースエンジニアリング — 提案LP

溶接アッセンブリー治具（Assy治具）のリバースエンジニアリング提案のための、静的シングルページランディングページです。H-ONE 様への提案・プレゼンテーション用に作成しました。ビルド不要・外部CDN不使用で、ファイル一式をそのままホスティングできます。

## 概要

- **提案主体**: アイ・シー・エンジニアリング株式会社（ICE / icej.co.jp）
- **言語切替**: ヘッダー右上の JP/EN トグルで日本語↔英語を切替（選択は localStorage に保存・既定は日本語）。翻訳辞書は `js/i18n.js`（日本語テキストをキーとする辞書方式）
- **計測パートナー**: ナベヤ製作所（岐阜県）
- **内容**: 図面のない治具を点群計測からCADモデル化し、エンジニアリング〜ハードウェア対応まで一気通貫で提供する提案
- **計測精度の記載**: FAROアーム等 **約0.05mm**／レーザートラッカー **約0.1mm**（測定機仕様に基づく目安）

## ローカル実行

ビルド手順は不要です。いずれかの方法で開いてください。

```bash
# 方法1: HTTPサーバー経由（推奨）
cd pointcloud-lp
python3 -m http.server 8080
# → http://localhost:8080 をブラウザで開く

# 方法2: ファイルを直接開く
# index.html をダブルクリック（file:// でも動作。外部リソースに依存しないため）
```

### テスト実行

```bash
cd pointcloud-lp
node test/anchors-test.js
```

検証内容: アンカーリンク（href↔id）の対応・外部リソース非依存・必須記載事項（H-ONE表記・計測精度0.05mm/0.1mm・JITの推測注記等）・HTML構造の基本チェック。

## デプロイ方法

静的ファイルのみのため、任意の静的ホスティングにそのまま置けます。

- **Netlify**: ディレクトリをドラッグ＆ドロップ、または `netlify deploy --dir .`
- **GitHub Pages**: リポジトリのルート（または `/docs`）に配置し Pages を有効化
- **S3 / 任意のWebサーバー**: `index.html` `css/` `js/` をそのままアップロード

## デザイン・技術仕様

- 日本語UI。白基調＋ディープブルー（`#16325c`）／スチール系アクセントの製造業向け配色
- 固定ヘッダー＋アンカーナビ（スクロールスパイ付き）。モバイル（≤980px）はハンバーガーメニュー
- スムーススクロール（`scroll-behavior: smooth` ＋ `scroll-padding-top`）
- IntersectionObserver によるスクロール連動表示アニメーション（`.reveal`）
- ヒーロー背景の点群は JS が決定論的乱数（XORShift32, seed固定）で生成 — 毎回同じ模様
- レスポンシブ: PC／タブレット／スマホ（760px以下ではSVGフロー図をHTML縦並びリストへ切替）
- **印刷対応**: `@media print` でナビ・アニメーション非表示・白背景・主要セクションのページ分割。`#contact` の「この提案資料を印刷 / PDF保存」ボタンから印刷ダイアログを開けます
- **外部ライブラリ・CDN・画像素材は不使用**。アイコン・図解はすべてインラインSVG、フォントはシステムフォント
- アクセシビリティ: `prefers-reduced-motion` 対応、`aria-*` 属性、フィールドセット化されたチェックリスト

## 表記上の注意

- 顧客名は「H-ONE」表記（「一番」表記は不使用）
- JITセクションは「参考ベンチマーク・推測を含む」ことをページ内に明記
- 計測精度（約0.05mm／約0.1mm）は測定機仕様に基づく目安であり、実測値の保証ではない旨をフッターに記載
